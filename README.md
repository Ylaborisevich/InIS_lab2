# Запуск проекта

Для запуска нужны установленные [Node.js](https://nodejs.org/) и npm.

Откройте терминал в папке `lab2` и выполните:

```bash
npm install --prefix blog-platform
npm run dev
```

После запуска откройте в браузере адрес http://localhost:5173/.

Чтобы остановить сервер, нажмите Ctrl+C в терминале.
